# 拾色 · 圖片純色工具

將圖片中相近的顏色統一為指定純色。純 HTML、CSS、JavaScript，無需安裝依賴或 API 金鑰，圖片全程在瀏覽器內處理。

## 開啟方式

直接使用現代瀏覽器開啟 `index.html`，或在專案目錄執行：

```sh
python3 -m http.server 8000
```

接著以瀏覽器開啟該服務。亦可將檔案部署到任意靜態網站服務。

若要合併成可攜的單一 HTML，在專案目錄執行：

```sh
python3 tools/build-standalone.py
```

輸出為 `dist/color-refiner.html`，CSS 與 JavaScript 已內嵌，不需其他檔案。這是本機產生的檔案；雲端工作目錄路徑不是公開下載網址。

## 使用流程

1. 上傳或拖曳圖片，也可按「試用範例」。
2. 拖曳框選處理區域，或輸入 X、Y、寬、高（原圖像素座標，從 0 起算）；預設處理整張圖片。
3. 切換「吸取顏色」，點擊圖片取樣，使用容差快速設定範圍，或分別填入 RGB 最小／最大值（0–255）。
4. 選擇目標純色，或輸入六位十六進位色碼，例如 `#FFFFFF`。
5. 預覽效果後按「套用純色」，可繼續處理其他顏色、復原或重設。
6. 按「下載 PNG」匯出已套用的結果。即時預覽不會自動匯出。

只有選取區域內、R/G/B **三個通道皆符合**範圍的像素才會替換，包含最小值與最大值。例如三個通道皆設 200–240，可將這個範圍內的淺灰色變成白色。這是 RGB 數值比對，並非辨識物件或自動去背。

每次替色都以目前已套用的圖片為基礎；吸色使用已套用的像素（查看原圖時則取原圖），不會吸取預覽色。完全透明的像素不處理，其他像素保留原透明度。下載保留原始像素尺寸，以 PNG 輸出，不保留原檔 EXIF 等中繼資料。

單張圖片最多 1,600 萬像素、檔案最大 50 MB。復原紀錄最多 10 步，並依影像大小限制在約 128 MiB 內；「重設圖片」始終可以回到上傳的原圖。復原與重設會關閉即時預覽，方便看清結果。重新載入網頁會清除圖片與修改。

## 驗證

不需安裝測試依賴，使用 Node.js 內建測試工具：

```sh
node --test tests/pixels.test.cjs
```

測試涵蓋 RGB 邊界、三通道比對、框選區域、透明度、來源資料保留及無效輸入。
